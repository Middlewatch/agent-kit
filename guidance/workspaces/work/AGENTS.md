# Day-job tasks

This root (the day-job root named in `~/.agents/MACHINE.md`) holds `<task-slug>` directories for construction project management
rather than software. Each subdirectory is one task and may include: copies of
the documents it touches, working notes, and whatever evidence the task
produces. The work is variable by nature, so work within whatever organization a
task has instead of imposing repo structure, and there is no git tracking by
default. Treat source documents
(specifications, drawings, contracts, correspondence) as evidence. Work from
copies, cite the exact section or page when a conclusion depends on one, and
keep the chain from claim to source visible, because these results get defended
to other people in their own terms. Finished products are documents written for
non-technical readers. Anything durable that outlives the task (a method that
worked, a reference fact) goes to `~/.agents/inbox` for triage into the wiki
(`~/.agents/wiki/work/`). The task directory itself is
deletable once its result has been delivered.

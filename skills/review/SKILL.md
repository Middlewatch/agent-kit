# Review

Produce findings that change how a reader understands or acts on the material.
Report without editing the reviewed material or filing a report unless the owner
asks. Working notes and scratch checks should stay in the scratchpad.

## Procedure

1. **Bound the review.** State the material, intended outcome, and exclusions in a
   short scope sentence. Use the requested criteria, or infer them from the
   material's purpose and state that assumption.
2. **Read and trace.** Read the relevant material and follow references that could
   establish or refute a finding. Use the global guide's context-hygiene rules for
   large corpora. Distinguish active instructions from historical evidence and
   quoted examples. Mark unavailable sources as coverage limits.
3. **Test each candidate.** Name the conflicting statements, missing assumption,
   or unsupported claim and its practical consequence. Check the strongest
   contrary interpretation, including scope and precedence, before retaining it.
   Separate direct conflicts, ambiguities, and preferences. Evidence should suit
   the material: paired passages can prove an instruction conflict without a
   runtime demonstration. Use a targeted check when it would settle uncertainty.
4. **Deliver.** Lead with the finding that most affects the requested outcome.
   Give each retained finding an alias, source citations, the consequence, any
   remaining uncertainty, and a suggested direction. End with brief coverage
   limits. If none survive scrutiny, say so and name what was checked.

The deliverable is the review itself. Remediation remains a separate task unless
already requested.

# review ledger

## 2026-09-29: lightweight non-code review
- Motivation: the instruction-kit audit exposed a gap between an informational
  review and the code-specific deep-review workflow. The owner requested a
  generic review skill while keeping the heavier workflows explicit-only.
- Change: add an automatically discoverable non-code review skill, extracted from
  that audit's scope, reference tracing, candidate refutation, and findings report.
  It does not require edits, durable filing, code gates, or executable proofs.
